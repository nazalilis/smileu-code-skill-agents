## 💡 What is Smileu Code Skill?

"Vibe coding" has unlocked unmatched development speed, but without structural discipline it quickly produces:
- **Hallucinated Architecture:** Agents inventing imaginary endpoints and tangled spaghetti dependencies.
- **AI Code Slop:** Generic purple-gradient landing pages, nested card-in-card containers, and jittery CSS animations.
- **Hidden Security Vulnerabilities:** Accidental hardcoded tokens, unchecked `eval()`, raw shell spawns, and vulnerable npm packages.
- **Robotic Fluff:** Documentation and commit messages packed with formulaic filler, dramatic inflation, and robotic throat-clearing.

**Smileu Code Skill** solves this by unifying 8 world-class engineering and design frameworks into an **executable CLI and multi-agent harness**. You can run it directly in any existing codebase using `npx`, with **zero mandatory external prerequisites**.

## ⚡ Quick Start: Isolated Copy-Paste Commands

Each command below is placed in its own dedicated block. Simply click the copy button on the command you need and paste it directly into your terminal.

### 1. Initialization & Project Setup

#### One-Command Install (Recommended)
Installs the **full library** (all 889 skills + 12 agent personas) plus the project truth files (`PRODUCT.md`, `CONTEXT.md`, `DESIGN.md`) and Architecture Decision Record templates across every supported editor. Run in a terminal and Smileu shows an interactive picker (editor + scope); pass `-y` to skip the prompts and take the defaults:
```bash
npx smileu-code-skill init
```

#### Core Suite Only (Lightweight)
Installs just the 9 curated meta-skills instead of the full library:
```bash
npx smileu-code-skill init --core
```

#### Pull the Latest from Upstream
Fetches skills directly from the reference repository into a temporary folder (needs `git` + internet), installs them, then cleans up — nothing is cached in your project:
```bash
npx smileu-code-skill init --latest
```

#### Setup for Cursor IDE Only
Configures Cursor-specific rules (`.cursor/rules/smileu.mdc` and `.cursorrules`):
```bash
npx smileu-code-skill init cursor
```

#### Setup for Claude Code Only
Configures Claude Code-specific guidelines (`CLAUDE.md`, `.claude/skills`, and `.claude/agents`):
```bash
npx smileu-code-skill init claude
```

#### Setup for Google Antigravity & Gemini CLI
Configures Antigravity / Gemini personas and tools (`.agent/skills` and `.agent/agents`):
```bash
npx smileu-code-skill init antigravity
```

#### Setup for Windsurf IDE
Configures Windsurf AI rules (`.windsurfrules`):
```bash
npx smileu-code-skill init windsurf
```

#### Setup Universal Markdown Rules
Installs generic markdown documentation suitable for any editor or git repository:
```bash
npx smileu-code-skill init universal
```

#### Dry-Run Simulation
Simulates the installation process without creating or modifying any files on disk:
```bash
npx smileu-code-skill init --dry-run
```

## 🧭 The Smileu 6-Phase Execution Harness

The core of Smileu Code Skill is a disciplined, chronological pipeline designed to prevent AI agents from skipping straight to unguided coding:

```
[1. ALIGN]     --> Grill intent, define scope, calibrate domain terms (PRODUCT.md & CONTEXT.md)
      ↓
[2. ARCHITECT] --> Build AST topology graph, detect god nodes, record architectural decisions (ADR)
      ↓
[3. SWARM]     --> Decompose subtasks across specialized agent personas using SPARC
      ↓
[4. CRAFT]     --> Enforce anti-slop design, harmonic typography (4px/8px), and natural spring motion
      ↓
[5. SECURE]    --> Validate input schemas, sanitize arguments, and audit OWASP Top 10 defenses
      ↓
[6. HUMANIZE]  --> Strip synthetic AI filler, robot drama, and state engineering facts plainly
```

## 💬 In-Editor Chat Triggers & Prompts

Once Smileu is initialized in your project, you can prompt your AI assistant (Cursor, Claude Code, Antigravity, or Windsurf) using these direct trigger prompts:

- **`/smileu align`** — Initiates a grilling session to uncover unstated assumptions and establish domain vocabulary.
- **`/smileu graph`** — Analyzes the codebase topology, identifies god nodes, and traces import dependencies.
- **`/smileu swarm "<task>"`** — Decomposes a feature into isolated SPARC tasks across the 5 agent personas.
- **`/smileu craft`** — Audits or writes frontend components enforcing anti-slop guidelines and spring physics.
- **`/smileu polish`** — Refines typography hierarchy, spacing rhythm, micro-interactions, and contrast.
- **`/smileu secure`** — Scans code for injection points, hardcoded secrets, and unsafe execution calls.
- **`/smileu humanize`** — Edits documentation, commit messages, and PR descriptions to read naturally without robot cliches.
- **`/smileu all`** — Executes the complete 6-Phase Pipeline end-to-end.

## 🚀 Release & Publishing Workflow


For maintainers and contributors wishing to publish updates:

#### 1. Bump Version & Prepare Release
```bash
node scripts/release.js patch    # For bug fixes (e.g. 1.0.1 -> 1.0.2)
```
```bash
node scripts/release.js minor    # For new features (e.g. 1.0.1 -> 1.1.0)
```
```bash
node scripts/release.js major    # For breaking changes (e.g. 1.0.1 -> 2.0.0)
```

#### 2. Push Commits & Git Tags to GitHub
```bash
git push origin main --tags
```
*Pushing a `v*` tag triggers the automated GitHub Actions workflow (`.github/workflows/release.yml`) to test across Node 18 & 20, create a GitHub Release, and publish the package to the npm registry.*
