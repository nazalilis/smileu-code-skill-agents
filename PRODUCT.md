# Product Truth: Smileu Code Skill

## 1. Audience
- **Primary Users:** AI-assisted developers, software engineers, and vibe coders using Cursor, Claude Code, Antigravity, Windsurf, Copilot, or terminal agents.
- **User Needs:** A unified, single-command (`npx`) setup that injects world-class engineering alignment, aesthetic taste, architecture knowledge graphs, animation physics, multi-agent swarms, security hardening, and humanized communication without configuring 8 separate tools manually.

## 2. Core Purpose
- **Mission Statement:** Consolidate the world's finest AI coding skills and agent methodologies into a cohesive meta-skill ("Smileu Code Skill") and an automated NPX installer.
- **Key Value Proposition:** Transform raw vibe coding into production-grade engineering: thoughtful alignment before coding, anti-slop frontend aesthetics, spring motion physics, robust security guardrails, and natural prose.

## 3. Operating Context & Constraints
- **Platform:** Cross-platform Node.js CLI (Windows, macOS, Linux).
- **Execution:** `npx smileu-code-skill` from npm, or `smileu` after a global install. GitHub Packages carries the same release as `@nazalilis/smileu-code-skill-agents`.
- **Target Editors:** Cursor (`.cursor/rules`), Claude Code (`.claude/skills`, `CLAUDE.md`), Antigravity/Gemini (`.agent/skills`), Windsurf (`.windsurfrules`), Universal (`.skills/`).
- **Dependencies:** Node.js 18 or later. Two small npm dependencies (`picocolors`, `prompts`); the CLI still works without them.
- **Updates:** Installed skills are refreshed with `smileu update`; releases are cut and published by GitHub Actions.

## 4. Brand Voice & Personality
- **Tone:** Sharp, intentional, pragmatic, disciplined, inspiring.
- **Anti-Tone:** Avoid robotic AI fluff, exaggerated claims ("game-changer", "revolutionary tapestry"), and superficial template boilerplate.
