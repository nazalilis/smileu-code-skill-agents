# Product Truth: [Project Name]

## 1. Audience
- **Primary Users:** Who is the core user persona using this software?
- **User Needs:** What specific pains or workflows are they trying to solve?

## 2. Core Purpose
- **Mission Statement:** [Describe the primary objective in 1-2 sentences.]
- **Key Value Proposition:** What makes this solution uniquely effective?

## 3. Operating Context & Constraints
- **Platform:** Web / Desktop / Mobile / CLI / Microservice
- **Performance Targets:** Response times, bundle size, latency boundaries.
- **Accessibility:** WCAG 2.1 AA compliance.
- **Security & Privacy:** Data classification, encryption in transit/rest.

## 4. Brand Voice & Personality
- **Tone:** Concise, direct, professional, transparent.
- **Anti-Tone:** Avoid corporate fluff, robotic jargon, and false cheerfulness.
